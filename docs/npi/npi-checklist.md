# NPI Checklist

## Product & Documentation

- [ ] Released BOM available
- [ ] Approved drawings/specifications available
- [ ] Product configuration rules defined
- [ ] Process flow released
- [ ] PFMEA reviewed
- [ ] Control plan reviewed
- [ ] SOPs/work instructions available at stations

## Equipment & Tooling

- [ ] Equipment installed and utilities verified
- [ ] Fixtures available and validated
- [ ] Torque tools programmed and verified
- [ ] Testers validated
- [ ] Barcode scanners/MES interfaces verified
- [ ] Calibration status current
- [ ] Spare parts / critical consumables identified

## Quality & Traceability

- [ ] Incoming inspection requirements defined
- [ ] In-process checkpoints defined
- [ ] Serial-number traceability verified
- [ ] Test results stored and retrievable
- [ ] Torque data stored where required
- [ ] Repair/failure codes defined
- [ ] Rework routing validated
- [ ] Final disposition logic verified

## Production Readiness

- [ ] Operator training complete
- [ ] Staffing plan verified
- [ ] Cycle time measured
- [ ] Takt/capacity reviewed
- [ ] Material presentation validated
- [ ] Safety/ergonomic review complete
- [ ] Pilot build issues closed or formally accepted
