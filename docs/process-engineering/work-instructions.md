# Work Instructions & SOPs

## Standard Page Structure

1. Purpose
2. Scope
3. Responsibilities
4. Safety / ESD requirements
5. Required tools and materials
6. Preconditions
7. Step-by-step procedure
8. Quality checkpoints
9. Failure / abnormal-condition response
10. Records and traceability
11. Revision history

!!! tip "Operator usability"
    Write instructions so the expected result can be observed or measured. Avoid subjective wording such as “push firmly” where force, travel, engagement, click, tool setting, or a visual acceptance criterion can be defined.
