# Process Engineering

This section contains the core manufacturing-process documentation used to define, control, validate, and improve production.

## Core Documents

| Document | Purpose |
|---|---|
| Process Flow | Defines the sequence, routing, decisions, rework and handoffs |
| PFMEA | Identifies process risks, causes, controls and recommended actions |
| Control Plan | Defines what is controlled, how it is measured and the reaction plan |
| SOP / WI | Defines how the operator or technician performs the process |

## Recommended Linkage

Every major production process should have traceability between:

**Process Flow → PFMEA → Control Plan → SOP/WI → Training Record**
